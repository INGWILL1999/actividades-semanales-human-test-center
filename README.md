# Actividades Semanales — Human Test Center

Sitio web estático para la gestión de actividades semanales del área **Sistema de Información, Seguridad y Calidad de Procesos** de **HUMAN TEST CENTER**.

**Creado por:** Ing. William Alvarez

## Publicar en GitHub Pages

1. Crea un repositorio nuevo en GitHub, por ejemplo `actividades-semanales`.
2. Sube `index.html` a la raíz del repositorio.
3. En GitHub abre **Settings → Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**.
5. Selecciona la rama `main` y la carpeta `/ (root)`.
6. Guarda. GitHub generará la dirección pública del sitio.

## Importante

El sitio funciona como página estática. Las actividades creadas, completadas o eliminadas se mantienen en la sesión/navegador y no se sincronizan con una base de datos.
